# Strizhi

Strizhi — Telegram-бот на базе .NET, предназначенный для автоматизации подготовки менеджеров по продажам к телефонным переговорам. Бот анализирует вводные данные о клиенте и с помощью GPT генерирует персонализированную стратегию звонка.

Статус проекта: релизный архив. Проект был полностью завершён, но не внедрён из-за сомнительной эффективности.

# 🛠 Технологический стек

* Платформа: .NET (C#)
* API: Telegram Bot API (через библиотеку Telegram.Bot)
* AI: OpenAI GPT API (генерация сценариев и анализ данных)

# 🎯 Основные возможности

* Анализ профиля: обработка сырых данных о потенциальном покупателе из файла.
* Стратегическое планирование: GPT формирует пошаговый план разговора (от «открывашки» до работы с возражениями).
* Подбор оффера: автоматический подбор наиболее подходящего продукта компании под конкретные боли клиента.
* Адаптивность: промпты настроены на создание живого диалога, а не сухого скрипта.

# 🚀 Процесс развёртывания

Для запуска необходимо скачать проект и скомпилировать его.

1. Установите .NET SDK
2. Запустите Strizhi.exe. В появившуюся папку добавьте файлы:

- TelegramBotToken.txt (токен, полученный у BotFather)
- GPTToken.txt (токен API OpenAI)
- offers.txt (примеры стратегий продаж, разделённые строкой "-----------------------------------")
- BotStructure.json

```json
{
  "Teg": "____",
  "ParentTeg": "",
  "MessageText": ".",
  "PromtNumber": -1,
  "ButtonsTexts": [],
  "ButtonsTegs": []
}
````

* Promt.json

```json
{
  "Namber": 5,
  "PromtText": "",
  "Hashtags": [],
  "Files": []
}
```

3. Запустите Strizhi.exe заново.
